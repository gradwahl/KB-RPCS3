Counts include return and some alignment NOPs. Audit distinguished three separate LLVM worker systems: `g_cfg.core.llvm_threads=10` limits **PPU LLVM compilation** (module queue and semaphore), while initial SPU cache precompilation uses an independently sized `SPU Worker ` pool (bounded by `rpcs3::utils::get_max_threads()` and queued programs), and **live SPU LLVM recompilation uses an `SPUW.` worker pool** calculated independently. Reducing `llvm_threads` alone is not equivalent to capping live SPU compiles.
